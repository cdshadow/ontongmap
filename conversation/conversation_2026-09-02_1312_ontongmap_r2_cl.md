**Claude:**

두 파일을 먼저 대조했습니다. `index.html`은 기존 스크립트가 만드는 folium 지도와 같은 뼈대를 가지고 있으며, 마커 97개의 좌표와 순서, 팝업·툴팁 내용까지 `place_map_template.csv`(100행, cp949)를 위에서부터 순서대로 지오코딩한 결과와 일치했습니다. 지오코딩에 실패해 지도에 실리지 않은 3건은 `(자)유한가스`, `오광인쇄(주)`, `우정주유소`였습니다.

기존 스크립트가 만드는 `facility_map.html`과 `index.html`의 차이는 네 가지였습니다.

첫째, 뷰포트 설정입니다. folium이 기본으로 넣는 `<meta name="viewport">`에 `viewport-fit=cover`가 덧붙어 있어 아이폰 노치 영역까지 지도가 채워집니다. 둘째, 화면 우측 상단에 고정되는 `#current-location` 버튼의 CSS가 `<head>`에 들어 있습니다. 셋째, `<body>`의 지도 `<div>` 바로 뒤에 `현위치` 버튼 요소가 있습니다. 넷째, `<script>` 끝에 Geolocation API로 현재 위치를 받아 파란 원형 마커와 정확도 원을 그리고 `setView(location, 16)`으로 이동하는 스크립트가 붙어 있습니다. 그리고 저장 파일명이 `facility_map.html`이 아니라 `index.html`입니다.

이 네 가지를 스크립트가 스스로 만들어 내도록 수정했습니다. 수정본은 원본을 덮어쓰지 않고 `place_map_api(perfect)_cl.py`로 저장했습니다.

구조는 다음과 같이 바꾸었습니다. 1~6번 구간(경로, API 키, 지오코딩 함수, CSV 읽기, 좌표 변환, 지도 생성)은 기존 로직을 그대로 두고 경로만 `os.path` 대신 `Path(__file__).parent` 기준으로 정리했습니다. 7번 구간에 버튼의 CSS, HTML, JavaScript를 각각 문자열 상수로 두었고, JavaScript 안에서 지도를 제어할 때 쓰는 변수명은 folium이 만들어 주는 임의의 이름이므로 `map_name = facility_map.get_name()`으로 받아 f-string으로 끼워 넣었습니다. 8번 구간에서 마커를 찍고, 9번 구간에서 렌더링 결과 문자열에 세 조각을 삽입합니다.

삽입 위치를 folium의 `add_child()`가 아니라 문자열 삽입으로 처리한 이유가 있습니다. 처음에는 `get_root().header.add_child()` 방식으로 만들었는데, folium은 CDN 링크와 지도 스타일을 렌더링 시점에 헤더에 덧붙이기 때문에 미리 추가한 CSS가 CDN 링크보다 앞에 놓이고, 버튼도 지도 `<div>`보다 앞에 놓여 `index.html`과 배치가 달라졌습니다. 그래서 렌더링이 끝난 HTML에 다음 세 자리를 기준으로 끼워 넣도록 바꾸었습니다.

```
CSS        : <head>의 지도 스타일 뒤, L_NO_TOUCH 스크립트 앞
HTML(버튼) : <body>의 지도 <div> 바로 뒤
JavaScript : 지도와 마커 생성 코드가 모두 끝난 </script> 앞
```

기준 문자열은 folium 템플릿에서 오는 것이므로, folium 버전이 올라가 기준 문자열이 사라지면 조용히 잘못된 파일이 나오지 않도록 `insert_before()`, `insert_after()` 안에서 위치를 찾지 못하면 `RuntimeError`를 내도록 했습니다.

마지막으로 저장 부분입니다. Windows에서 파이썬이 기본으로 텍스트를 쓰면 개행이 CRLF가 되는데 원본 `index.html`은 LF이므로, `open(output_file, "w", encoding="utf-8", newline="\n")`으로 저장하고 파일 끝에 줄바꿈 하나를 남기도록 했습니다. 실행이 끝나면 전체 건수와 표시 건수, 좌표 변환에 실패한 상호명을 함께 출력합니다.

검증은 원본 `index.html`을 건드리지 않도록 임시 폴더에 `.py`, `.env`, `place_map_template.csv`를 복사해 실행하는 방식으로 했습니다. 실행 결과는 다음과 같습니다.
